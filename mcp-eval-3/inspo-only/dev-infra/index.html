One primitive. Every durable pattern.

A single function call gives you queues, schedules, fan-out, sagas, and human-in-the-loop. We persist every step so the runtime can resume exactly where it left off.

Step-level retries

Wrap any side effect in step.run() and Conduit memoises the result. Failures resume from the last successful step — no manual checkpoints, no idempotency keys to invent.

retry · backoff · replay

Sleep without paying

Pause a workflow for minutes, days, or quarters. Sleeping runs cost nothing — they live in storage until the timer fires or an event wakes them. Perfect for trials, renewals, and SLAs.

durable sleep · cron · events

Observability built in

Every step shipped to the dashboard with inputs, outputs, and the actual stack trace. Replay a failed run against today’s code in one click. Logs are searchable for 30 days on every plan.

traces · replay · alerts

import { conduit } from "@conduit/sdk";

export const fulfillOrder = conduit.createFunction(
  { id: "fulfill-order", concurrency: { limit: 8, key: "event.data.tenantId" } },
  { event: "order/placed" },
  async ({ event, step }) => {

    // step.run() memoises — safe to retry the whole function.
    const charge = await step.run("charge-card", () =>
      stripe.charges.create({ amount: event.data.total })
    );

    // Sleep for free. Wakes itself in 24h or earlier on event.
    await step.sleep("hold-for-fraud-check", "24h");

    await step.run("hand-off-to-3pl", () => warehouse.ship(event.data));

    return { chargeId: charge.id, shipped: true };
  }
);
from conduit import Conduit, Step

app = Conduit("acme")

@app.function(
    id="fulfill-order",
    trigger="order/placed",
    concurrency={"limit": 8, "key": "data.tenantId"},
)
async def fulfill_order(event, step: Step):
    # step.run() memoises — safe to retry the whole function.
    charge = await step.run("charge-card",
        lambda: stripe.charges.create(amount=event.data.total))

    await step.sleep("hold-for-fraud-check", "24h")

    await step.run("hand-off-to-3pl",
        lambda: warehouse.ship(event.data))

    return {"charge_id": charge.id, "shipped": True}
package workflows

import (
  "context"
  "github.com/conduit/sdk-go"
)

var FulfillOrder = conduit.Function(
  conduit.Config{
    ID: "fulfill-order",
    Concurrency: conduit.Concurrency{Limit: 8, Key: "event.data.tenantId"},
  },
  conduit.On("order/placed"),
  func(ctx context.Context, e *conduit.Event, s *conduit.Step) (any, error) {

    charge, err := s.Run("charge-card", func() (any, error) {
      return stripe.Charge(e.Data.Total)
    })
    if err != nil { return nil, err }

    s.Sleep("hold-for-fraud-check", "24h")
    s.Run("hand-off-to-3pl", func() (any, error) { return warehouse.Ship(e.Data) })

    return charge, nil
  },
)

// answers

Common questions.

Still unclear? read the docs or ping hello@conduit.run.

How is this different from a queue like SQS or Sidekiq?
Queues hand you a message; you still write the retry loop, the deadletter handler, the idempotency layer, the observability shim, and the cron scheduler. Conduit gives you all of those as a single primitive (step.run) and persists the result of every step so failures resume exactly where they stopped — not from the top.
Do I have to rewrite my existing handlers?
No. Wrap any side-effect call in step.run("name", () => ...) and you’re done. Most teams migrate one job at a time and run Conduit alongside their existing queue until they’ve drained it.
Where does Conduit run my code?
Your code runs in your own infrastructure. Conduit is the durable router and state store — it hosts the dashboard, schedules events, and calls your endpoints. Code, secrets, and customer data never leave your VPC. Self-hosting the router is available on Enterprise.
What languages and frameworks do you support?
First-class SDKs for TypeScript, Python, Go, and Elixir. Anything that can serve an HTTP endpoint can use the JSON protocol directly. Native integrations for Next.js, FastAPI, Express, Fiber, Phoenix, and Hono.
How do you price “a run”?
A run is one function invocation, regardless of how many steps it contains. Sleeping runs cost nothing — we only meter steps that execute. There are no per-CPU charges and no idle worker fees.
Is there a free tier I can leave running?
Yes. The Hobby plan stays free indefinitely up to 100,000 runs per month. We don’t expire projects, sunset accounts, or paywall production usage on the free tier.
