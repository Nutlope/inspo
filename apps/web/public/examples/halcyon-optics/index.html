02 / The Optics

Every element is tested before it earns a serial number.

Figured, not moulded

Each surface is polished against a test plate and corrected by hand. A moulded element is fast and repeatable; it is also within a wave of correct, which is not the same as correct.

Tested on a real star

Interferometry says what the glass is. An artificial star at 400× says what you will see. We do both, and ship the plots for both.

Rejected if it fails

Roughly one element in nine does not make it out of the shop. That is the whole reason we can only build eighteen instruments a month.
