How it works

From zero to full visibility in three steps.

No agents to babysit, no pipeline to build. Tracewell instruments what you already run and streams everything into one correlated view.

1 Install the SDK

One line, every runtime.

Drop the Tracewell SDK into your service. We auto-instrument HTTP, gRPC, DB calls, and queues for Go, Node, Python, Rust, and JVM - no manual spans required.

npm i @tracewell/node # or
2 Point at your stack

We pick up the signals.

Tracewell ingests OpenTelemetry, syslog, Prometheus, and your existing structured logs. No schema migration, no rewrite - keep the exporters you already have.

TRACEWELL_ENDPOINT=ingest.tracewell.io
3 Query in seconds

One timeline, every signal.

Jump from a metric anomaly to the offending span to the exact log line - all in one view. No tab-switching, no correlation by hand.

trace.show "checkout-7f2a" --tail
