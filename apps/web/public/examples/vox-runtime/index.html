How it works

An agent is a function. The call is the runtime.

No call graphs to draw, no IVR trees to maintain. Define the behavior in code, give it tools, and Larynx runs the conversation — speech, timing, interruptions and all.

agent.ts 
// support line — reschedules & refunds
import { Agent, tool } from "@larynx/runtime"

export default new Agent({
  voice: "ash",
  latency: "realtime",   // ~287ms turns
  bargeIn: true,

  prompt: `You are Northwind's support line.
  Be warm, brief, and never guess an order.`,

  tools: [
    tool("reschedule_order", rescheduleOrder),
    tool("issue_refund",      issueRefund),
  ],
})

// $ larynx deploy --number +14155550118
