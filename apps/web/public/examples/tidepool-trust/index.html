Three things, done slowly.

Restoration is unglamorous and takes a decade. We do not run campaigns about it; we run surveys.

Seed

Grown from local stock

Spores are collected from surviving beds within eight kilometres of each site, cultured on twine, and planted by hand from a small boat. Imported stock does not hold.

Protect

Urchin control, not urchin removal

Grazing collapse is what killed these beds. We thin urchin density to a threshold and then leave the site alone, because a barren with no urchins is also a dead one.

Measure

Counted four times a year

Divers run the same transects each quarter. Canopy cover, holdfast density, and fish counts go into the public dataset within thirty days, unedited.
