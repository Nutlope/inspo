Three steps, one afternoon back.

Box 03Held codes

Most holds are not random.

They follow a short list of triggers, and every one of them is visible in the paperwork before you file. Manifest checks each line against that list, then tells you what to change while the change is still free.

  • Missing partner agency data. A code that needs an FDA, USDA or Lacey declaration, filed without one.
  • Descriptions too vague to classify. "Household goods" invites an exam. A precise line does not.
  • Anti-dumping scope you did not know about. Some codes carry open cases; origin decides whether yours is in scope.
  • Values out of line with the code. A declared value far from the norm for that classification draws a review.

Box 05Questions

Asked by every importer we talk to.

Do I still need a customs broker?

For routine consumption entries, no: you file under your own importer of record and Manifest prepares everything the filing needs. Genuinely hard cases, like an anti-dumping scope question or a protest, deserve a specialist, and Manifest tells you when a line looks like one instead of pretending it does not.

Which imports does it cover?

Imports into the United States: ocean, air and truck entries at any U.S. port. If you import somewhere else, Manifest is not for you yet.

What does it cost?

A flat fee per entry, shown before you file it. No retainer, no annual minimum, no charge for the slow months. The price is on the review screen, next to the duties, before anything is submitted.

What happens if a shipment is held anyway?

Manifest shows the hold reason exactly as customs states it, assembles the response paperwork, and keeps the record on the entry, so the same code never surprises you twice.
